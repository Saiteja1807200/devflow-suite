# UI Direction

```text
+-----------------+--------------------------------------------------+
| DevFlow          | Search work...                 alerts  profile |
| Dashboard        +--------------------------------------------------+
| My work          | Delivery overview                                |
| Projects         | [Active projects] [My tasks] [Completed]        |
| Calendar         |                                                  |
| Reports          |  Project health chart    Recent activity        |
| Settings         |                                                  |
+-----------------+--------------------------------------------------+
```

The project screen keeps board controls close to the work: breadcrumb, project status, member avatars, filters, and an accessible create-task action above fixed-width Kanban columns. Small screens collapse the sidebar and preserve quick access to the active project and task creation.
